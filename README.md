# 🎲 Yutnori Game

A modern web-based implementation of the traditional **Korean Yutnori Board Game**. This project recreates the classic Yutnori experience with a modern interface, customizable players, multilingual support, and an enjoyable gameplay experience.

🌐 **Live Demo**

## 🎯 Gameplay

Players throw four traditional **Yut sticks** to determine how many spaces they can move on the board.

### Possible Outcomes

| Result | Movement | Extra Turn |
|:------:|:--------:|:----------:|
| **Do** | 1 Step |   No |
| **Gae** | 2 Steps |   No |
| **Geol** | 3 Steps |   No |
| **Yut** | 4 Steps | ✅ Yes |
| **Mo** | 5 Steps | ✅ Yes |

> **Note:** Rolling **Yut** or **Mo** grants the player **one additional throw** before the turn ends.

### Objective

The objective of the game is to move all four pieces around the board and reach the finish before the opposing team(s).

During the game, players can:

- Move pieces according to the Yut stick result.
- Capture opponent pieces and send them back to the starting area.
- Stack friendly pieces together and move them as a single group.
- Use shortcut paths to reach the finish faster.
- Win by successfully finishing all four pieces.
